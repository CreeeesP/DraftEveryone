  Draft Everyone — Control Everyone

Draft Everyone expands RimWorld's draft system, allowing the player to directly control almost any creature encountered in the game.

Vanilla RimWorld limits drafting to colonists. This mod removes that restriction.

With Draft Everyone, you can directly control:

- animals;
- friendly, neutral, and hostile pawns;
- mechanoids;
- anomalous entities;

Once control is enabled, the selected pawn can use the standard drafting system: move according to the player's orders, receive commands, and use available abilities and weapons.

  The Basic Idea

Select a pawn → take control of it → give orders just like you would to a colonist.

This opens up a wide range of possibilities:

* manually controlling animals in combat;
* controlling anomalous entities;
* controlling mechs;
* tactically controlling friendly or hostile pawns;
* various experiments and alternative ways to play the game.

The mod is designed to expand RimWorld's existing draft system rather than replace it.

Draft Everyone — because everyone can be drafted.

The mod was developed with the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3530313037]Just Leave Already[/url] mod in mind, and I strongly recommend using it so that all controlled pawns and animals can be forced to leave the map. Support for the [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3546716725]Walk the World[/url] mod is also implemented, although it may work with some delay and may not succeed on the first attempt.

This mod was originally born from a desire to fix bugs in [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2471500864]Draft Anything[/url]. However, while working on those issues, I decided to change some parts of the implementation. As a result, the mod was substantially reworked and is, in many ways, a new implementation of the original idea.

Some remnants of the original mod's code and design decisions are still present, while the core concept of controlling all pawns through the draft system has been preserved.
